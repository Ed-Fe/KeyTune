# Changelog

All notable changes to this project are documented in [`docs/changelog/`](docs/changelog/), one file per version.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

- `X.Y.Z.md` is the version's text in Portuguese (the source language), `X.Y.Z.en.md` is the English translation and `X.Y.Z.es.md` the Spanish one.
- `unreleased.md` (and `.en`/`.es`) holds what is not released yet.
- Inside KeyTune, **Ajuda > Histórico de mudanças** shows these files in the language of the interface.
