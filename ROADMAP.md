# Roadmap

This roadmap covers the next major version of KeyTune.

## Next Major Version

### Translation System

- Move user-facing strings into translation catalogs
- Add a language selection setting in preferences
- Provide a fallback language when a translation is incomplete or unavailable
- Update the documentation and release notes to explain language support

### Related Improvements

- Review the remaining hard-coded strings in the UI layer
- Make the translation workflow easy to maintain for future contributors
