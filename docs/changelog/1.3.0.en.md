## [1.3.0] - 2026-08-03

### Added
- **Search in the current playlist or folder**: `Ctrl+F` opens the **Find item** box, which looks for the text anywhere in the name, ignoring accents and capitalization. `F3` goes to the next result and `Shift+F3` to the previous one, with the position in the search and the notice that it wrapped back to the start of the list in the status bar. Also available in **View > Find item**.
- **Sleep timer**: `Ctrl+Shift+D` (or **Playback > Sleep timer**) schedules an automatic pause with ready-made durations from 5 to 120 minutes, a custom time or at the end of the current track. The menu also has **Time remaining** and **Cancel timer**, there are spoken warnings at 5 minutes and 1 minute left, and the state is included in the status announcement (`S` key).
- **YouTube Music connection through the browser**: direct extraction of the cookies of a session already signed in on Chrome, Edge, Firefox, Brave or Opera, with a switch between browser and manual modes in the connection box.
- **Skip the track when you mark "dislike"**: `Ctrl+Shift+L` automatically moves to the next track when you mark the current media as disliked on YouTube Music, but only when the rated item is actually the one playing at that moment.

### Fixed
- **Like/dislike gave a false alarm**: the like confirmation checked the status on the server right after sending the rating, but the YouTube Music API propagates it asynchronously and often still returned the previous status — which sounded as if the rating had not been accepted. Now it trusts the rating that was sent and correctly announces "Current media liked" / "marked as disliked".
- **Repeated tracks in related content**: the YouTube Music radio builds a new queue on every query and returns the tracks around the seed, so songs already in the playlist were added again — including the one you had added yourself from the search. Now the comparison is by `videoId` (the radio URL embeds a queue identifier that changes on every query, so it was no use), the player tries to continue the previous queue instead of opening a new one, and seeds the radio again from an earlier track when the query brings only repeats.
- **Plurals in messages**: counts of items, tracks, playlists, mixes, results, devices and minutes now use real singular and plural forms ("216 items", "1 minute") instead of the abbreviations "item(s)" and "minute(s)", in Portuguese, English and Spanish.
- **Saved results in YouTube Music**: the confirmation message can be translated again.
