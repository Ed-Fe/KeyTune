## [2.0.3] - 2026-09-05

### Fixed

- **YouTube Music additional resources**: the update preserves the user profile's permissions when replacing optional resources. Old folders that cannot be opened are recovered into a repair folder, without blocking the download.
- **YouTube Music account validation**: the absence of the optional libraries now says that the features need to be enabled or updated, instead of wrongly pointing to an invalid account.
- **YouTube Music radio**: radio responses without an endpoint in an optional tab no longer interrupt the song queue, and simultaneous searches correctly restore the library parser.
