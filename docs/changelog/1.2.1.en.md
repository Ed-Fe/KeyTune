## [1.2.1] - 2026-07-27

### Fixed
- **Automatic playlist playback**: playlists prepared by YouTube Music start the first track correctly again.

- **Release notes**: preserves UTF-8 encoding when publishing to GitHub and shows the content as plain text in the update dialog.
