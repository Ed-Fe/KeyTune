## [2.0.0] - 2026-09-04

KeyTune 2.0 brings AutoDJ to build sessions and mix songs, a plugin platform with a marketplace, and YouTube.js integration for YouTube playback. The release also expands folder navigation and the YouTube Music features.

### AutoDJ

- **Automatic mixing**: the new AutoDJ analyzes the rhythm, BPM, key, energy and loudness of the songs to choose the sequence and prepare transitions. When the analysis allows, it syncs the beats, aligns musical phrases and gradually swaps the bass and mids between tracks. It also takes vocal overlap and volume differences into account.
- **Sessions from playlists**: the **Play playlist with AutoDJ** action opens its own tab, keeps the original playlist and holds up to five prepared songs ahead. The manual queue takes priority, and the session can be restored when the player is reopened.
- **Sequence control**: you can replace the next song, recalculate the sequence, add files, pause or resume the preparation, and end the session keeping the prepared stretch as a regular playlist.
- **Profiles and effects**: choose between **Smooth**, **Party** and **Electronic**, set transitions of 8, 16 or 32 beats and enable optional DJ effects.
- **Accessible information**: the session tab shows the state of the tracks, the analysis activity and the details of the next transition, including BPM, tempo adjustment and rhythm confidence. The information and the controls are accessible by keyboard and screen reader.
- **Local and online songs**: AutoDJ can also analyze YouTube Music tracks and compatible URLs, reusing cached analyses. When there is not enough analysis, it uses the regular crossfade that is configured or simply moves on.

### Plugins and marketplace

- **A new extension platform**: plugins can add menu actions, tabs, screens and integrations to KeyTune.
- **Accessible manager**: install `.ktplugin` packages, and enable, disable and uninstall extensions in **Settings > Manage plugins**, with keyboard navigation.
- **Built-in marketplace**: discover and install plugins from the community catalog. Authors can publish their packages and submit contributions to the catalog through pull requests on GitHub.
- **Permissions and installation confirmation**: before installing and enabling a plugin, the player shows the author, version, origin, permissions and isolation mode. Marketplace packages have their integrity verified. The separate process helps contain failures, but it is not a security sandbox; install only plugins from authors you trust.
- **Public API 2.0**: developers get permission-based access to playback, open playlists, the smart library, YouTube Music, extraction and downloads through yt-dlp, AutoDJ analysis, network, text files, the clipboard, private settings and accessible notifications.
- **Guides in three languages**: API documentation, examples, manifest, events and publishing instructions in Portuguese, English and Spanish, included as HTML with the player for offline reference.

### YouTube and YouTube Music

- **Introducing YouTube.js**: a new media resolution option for playing YouTube and YouTube Music. It can be enabled in **Preferences > Additional resources** and shares Node.js with yt-dlp, which stays available as a fallback when resolution through YouTube.js fails.
- **Radio from the current track**: `Ctrl+R`, or **Playback > Start radio from this track**, creates a radio in a new tab without interrupting the music or losing its position. The current track starts the list, and the recent history helps reduce repeats.
- **Filter for songs marked "dislike"**: the player keeps these ratings per account to remove tracks from loaded playlists and radios and to skip them in restored queues. **Refresh library** also queries the ratings available on the account; ratings made on other devices are picked up when they show up in YouTube Music responses.
- **Opening playlists from the clipboard**: `Ctrl+V` recognizes YouTube Music playlist links, opens the full list and starts the first track, including when used on screen tabs.

### Folder navigation

- **File sorting**: `Ctrl+Space` opens options to sort by name, modification date, creation date, type or size, in ascending or descending order. Folders stay grouped before files, and the choice is restored with the tab.
- **Copying to Windows Explorer**: in the folder browser, `Ctrl+C` copies the selected files or folders so you can paste them in Explorer. `Ctrl+Shift+C` copies their paths as text; on other tabs, it keeps copying the link or path of the media that is playing.

### Optional resource installation

- **On-demand components**: the YouTube libraries, YouTube.js, portable Node.js and the AutoDJ analyzer are distributed separately from the main installer. In **Preferences > Additional resources**, the player shows the components needed before downloading.
- **Shared runtime**: yt-dlp and YouTube.js use the same Node.js, with Node.js 24 or later recommended. The player reuses a compatible runtime that is already installed or prepares the portable version it needs.
- **Verification and reuse**: the optional packages have integrity verification and are tied to the KeyTune version. Valid components that are already installed are reused, and disabling a feature keeps the downloaded files. yt-dlp keeps receiving updates through the stable or nightly channel you chose.
