## [1.4.0] - 2026-08-17

### Added
- **Local smart library**: new **Library** menu with global search (`Ctrl+G`), folder indexing and filters by favorites, ratings and plays. The data stays only on the computer and the feature can be turned off in the preferences.
- **Favorites and ratings**: `Ctrl+D` toggles favorites and `Ctrl+0` to `Ctrl+5` sets the rating, with visible markers and accessible announcements in the item list.
- **Playback history**: `Ctrl+Shift+H` opens the searchable history, with views by play, by media or by most played.
- **Resume and Continue listening**: long media can return from the saved point; `Ctrl+Shift+R` gathers the content you left halfway.
- **Smart playlists**: rules combine folder, favorites, rating, history and sorting to build lists that update automatically.
- **Shortcut to copy the link of the media that is playing**: `Ctrl+Shift+C` copies the link or path of the current media straight to the clipboard on any tab, with a screen reader announcement.

### Fixed
- **Real-time check of likes on YouTube Music**: the status check when liking or unliking (`Ctrl+L`) queries the YouTube Music API queue live and uses an in-memory cache, correctly identifying tracks that had already been liked on the user's account.
- **Clean window title formatting**: during playback the window title shows `KeyTune — [Track name]` directly, omitting generic tab labels and raw YouTube URLs (`watch?v=...`).
