## [2.0.4] - 2026-09-05

### Fixed

- **AutoDJ**: fixed the analysis that could enter an infinite loop after a native failure. The preparation now pauses with a clear error, and transitions without analysis use the regular crossfade without retrying automatically.
- **AutoDJ resources**: the analyzer now reuses KeyTune's Python runtime. The optional package contains only the scientific libraries it needs, without bundling a second copy of Python or another application executable.
- **Analysis stability**: pinned compatible versions of NumPy, SciPy, Numba and llvmlite, with analysis validated in the packaged executable.
- **Windows packaging**: the optional scientific libraries are no longer copied into the main executable, avoiding conflicts between copies of AutoDJ.
- **Resource updates**: valid Node.js, YouTube Python and YouTube.js are reused across player updates; only resources with an incompatible revision are downloaded again.
