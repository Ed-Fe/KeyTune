## [Unreleased]

### Added

- **User manual in a program window**: **Help > Open user manual** (and the button on the welcome screen) no longer opens the browser. The window has five fields: **Search the manual**, **Sections**, **Topics in the section**, **Text** and **Links in the topic**. Choose with the arrow keys and press `Enter` to go to the next field; `Esc` closes. Each field also has a shortcut: `Alt+S` goes to the search, `Alt+T` to the sections, `Alt+O` to the topics, `Alt+X` to the text and `Alt+L` to the links. The manual's links work: `Enter` on an item of **Links in the topic**, or on a line of the text that has a link, follows the link. A part of the manual opens in the window itself, with the focus on the text; a website opens in the browser. In the search, type one or more words and press `Enter`: the lists show only the topics that have all of them (ignoring case and accents), the program says how many it found and the text opens on the line with the word. `Enter` with the field empty brings the whole manual back. Each topic is short, and the shortcut tables become "key: what it does" lines. It follows the program language.
- **Spoken notices split by kind**: in **Preferences > Accessibility**, the **Notices that speak** list now has eight new kinds, besides the five event kinds that already existed: playback; track change and SponsorBlock; speed and pitch; modes turned on or off; navigation; progress; confirmations; and errors and unavailable actions. You can silence the track change and keep the time, volume and status you ask for with `T`, `V` and `S`, for example. Those three keys do not depend on the list. All of them come on, and the **Enable accessibility announcements** switch still applies on top. The option to speak while KeyTune is active still covers only the notices that arrive by themselves (chat, notifications, download and sleep timer).
- **Open KeyTube on startup**: in **Preferences > General > Startup and session**, **Open KeyTube on startup** opens the KeyTube tab together with the app. It is off by default and available only with the YouTube integration turned on in **Additional resources**.
