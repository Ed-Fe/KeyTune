## [Unreleased]

### Added

- **Publish a radio station to the directory**: in the **Online radio** tab, **Add radio to the directory...** (the button next to **Add radio manually...**, or the same item in the **Actions...** menu) registers the station on Radio Browser. The listing is public and KeyTune cannot undo or edit it. If the address already exists, KeyTune says the name of the station that is already there and does not send it. If the directory refuses, the check fails, or the answer does not arrive after sending, it shows what happened and asks whether you want to return to the form, with No selected. When the answer does not arrive, search for the station before trying again.

### Changed

- **Sounds in the radio lists**: the **Online radio** tab now plays the same notification sounds as KeyTube when opening a list, going back to the previous one and loading more items.

### Fixed

- **Equalizer preset editor description**: when it opens, the screen reader now reads only the introduction, without the help texts and band labels.
