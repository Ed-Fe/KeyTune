## [2.0.4] - 2026-09-05

### Corregido

- **AutoDJ**: se corrigió el análisis que podía entrar en un bucle infinito tras un fallo nativo. La preparación ahora se pausa con un error claro, y las transiciones sin análisis usan el crossfade normal sin repetir intentos automáticamente.
- **Recursos de AutoDJ**: el analizador ahora reutiliza el runtime de Python de KeyTune. El paquete opcional contiene solo las bibliotecas científicas necesarias, sin empaquetar una segunda copia de Python ni otro ejecutable de la aplicación.
- **Estabilidad del análisis**: se fijaron versiones compatibles de NumPy, SciPy, Numba y llvmlite, con validación del análisis en el ejecutable empaquetado.
- **Empaquetado de Windows**: las bibliotecas científicas opcionales ya no se copian en el ejecutable principal, evitando conflictos entre copias de AutoDJ.
- **Actualizaciones de recursos**: Node.js, YouTube Python y YouTube.js válidos se reutilizan entre actualizaciones del reproductor; solo se vuelven a descargar los recursos con una revisión incompatible.
